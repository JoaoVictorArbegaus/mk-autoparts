# 07 — Contrato da API

**Fora do escopo do protótipo** (`DEC-001`). Não há API.

O frontend lê os dados por funções de acesso em `frontend/src/content/` (ex.:
`listarProdutos`, `buscarProduto(slug)`), para que, no produto definitivo, essas
funções sejam trocadas por chamadas à API sem reescrever os componentes
(`10-architecture.md`).

O contrato da API do produto definitivo será escrito depois da apresentação, usando
`D:\IntelliJ\Workspace\KiProdutos\sdd_kit\07-api-contract.md` como referência de
formato.
